# Contributing

This is **Ripple**, the Dash-mounted ephemeral intent surface. AODL is a different repository.

1. Search open issues and PRs. Do not duplicate the AODL catalog.
2. Branch from default. Open a PR. **Do not merge `main`.**
3. `bun test src` must stay green. Pin geometry if you touch layout.
4. No native modules outside the Expo SDK. No HOTL schema.
5. Product name is Ripple. Do not revive `aodl-ui` / `IntentSurface`.

See [AGENTS.md](AGENTS.md).
